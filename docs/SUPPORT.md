# Support checklist

Before reporting a problem:
1. Confirm the terminal says `Multi-Script Bridge v4.0.0`.
2. Open **Help → Test provider**.
3. Use **Help → Copy diagnostics**.
4. Confirm the target editor is open and its MCP connection is enabled.
5. Reproduce in a new empty chat.
6. Remove secrets and private workspace content from all logs/screenshots.

Include: OS, browser version, provider, target engine, exact steps, expected behavior, actual behavior, and sanitized diagnostics.
