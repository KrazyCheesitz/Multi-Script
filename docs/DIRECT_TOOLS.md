# Direct Multi-Script tools — 6.19.0

Multi-Script exposes 230 direct bridge tools. They include engine/catalog discovery, schema assurance, project verification, media and desktop helpers, production specialists, and reusable workflows. The 24 Roblox additions cover DataModel architecture, remote security, persistence and cross-server reliability, StreamingEnabled, Parallel Luau/Actors, character and animation runtime, multi-device UI/input, VR, physics ownership, scalable NPCs, MicroProfiler/render budgets, asset delivery, live operations, monetization, localization, accessibility, multi-client testing, and release readiness.

Each new command returns an eight-stage execution contract and eight evidence-based quality gates. These contracts are task-first: the agent must then inspect the project, call the real connected MCP tools, create or modify the requested deliverable, test it, and read back final state. A plan alone is not completion.


Version 4.9.0 adds exact-server catalogue, call, connection-test and capability-map commands plus 29 production specialists.

The generic MCP discovery surface already includes:

- `ms_list_resources` / `ms_read_resource` expose standard MCP resources.
- `ms_engine_catalog` / `ms_call_engine_tool` discover and call the exact native tools advertised by any configured server.

These are provider-independent. The same live bridge catalog is available from every supported AI site, and Multi-Script does not register duplicate direct tools for server-native capabilities.
